# 任务：创建备忘录并核验（Apple 备忘录）

## 定位

- 输入：标题（必需）+ 正文（可选，可含换行、中文标点）。
- 输出：一条新建备忘录 + 重新打开后的逐字核验结果。
- 考察点：中文、换行、标点的输入正确性，以及**重试时不重复创建**。

## 硬边界

- 只操作「备忘录」App。
- 不修改、不删除任何既有备忘录。
- 备忘录被屏幕使用时间锁定或要求密码 → 停止，交给用户。

## 流程

### 1. 检查

- 镜像连接正常（本会话 setup 自检已通过）。
- 打开「备忘录」。若停在异常页（锁定提示、空白加载），按硬边界与 recovery.md 处理。

### 2. 幂等检查（关键，防止重复创建）

- 进入备忘录列表 → 搜索目标标题（精确匹配）。
- 命中且是**本会话本次任务**已创建的 → 不再创建，直接进入第 4 步核验。
- 命中但是**以前就存在**的同名备忘录 → 停下询问用户：新建一条，还是查看既有那条？不得擅自二选一。
- 未命中 → 进入创建流程。

### 3. 创建

1. 新建备忘录。
2. 光标落在标题行：输入标题 → 换行。
3. 输入正文（含换行时逐段输入）。
4. 点「完成」收起编辑。

输入规则（硬性）：

- 先确认输入方式：直接键入，或剪贴板粘贴。粘贴前备份剪贴板内容，任务结束恢复，恢复失败要报告。
- 每次输入后**回读整个字段**，逐字核对标题与正文（含标点、换行）。iOS 自动更正/联想可能改动文字，核对以屏幕实际显示为准。
- 回读不一致 → 全选删除 → 换另一种输入方式重试**一次** → 仍不一致 → 停止报告，不继续保存动作。
- 警惕默认标题陷阱：标题输入失败时备忘录会保持「新建备忘录」字样，核验时必须发现这一点。

### 4. 核验

- 返回列表 → 找到该备忘录 → 重新打开。
- 标题逐字比对；正文逐字比对（含换行与标点）。
- **如果不确定刚才是否保存成功**：先回列表搜索该标题，确认存在与否，再决定下一步；绝不能直接再创建一条。

### 5. 重试预算

- 创建动作（含输入）最多 2 次完整尝试。
- 触顶 → 停止，报告：已输入到什么程度、屏幕当前显示什么、建议用户怎么收尾（例如手动删除残留草稿）。

## 汇报

- 最终标题与正文（按屏幕回读的版本）。
- 核验证据：重新打开后看到的内容。
- 当前停留页面。
- 不确定之处（如有）。
