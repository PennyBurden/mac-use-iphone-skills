# 恢复规则：断连、弹窗、输入失败

总原则：**恢复动作本身也走核心操作循环**（观察 → 操作 → 验证），所有恢复尝试计入重试预算。宁可停下报告，不盲目多点。

## 1. 镜像断开

- 症状：镜像窗口消失、黑屏、出现「连接已断开」提示。
- 动作：**立即停止一切点击**。报告：已完成步骤、最后确认过的状态、断开时间点。
- 重连是用户的事；重连后经用户同意再从中断点继续（先重新观察再动）。

## 2. 弹窗

先读全文再决定，按类型分治：

| 类型 | 处理 |
|---|---|
| 系统权限弹窗（通知/定位等） | 只在挡住任务时处理；优先「稍后」这类中性选项；没有中性选项 → 报告交用户 |
| App 促销/升级弹窗 | 找「关闭 ×」「跳过」「稍后」；找不到 → 报告 |
| 未知或看不懂的弹窗 | **不点击**，报告内容与按钮文字 |
| 含「支付/确认/删除/发送/下单」的弹窗 | 一律不点，交用户 |

## 3. 输入失败（文字缺失/错字/乱码）

1. 清空该输入框。
2. 换输入方式重试一次（直接键入 ↔ 剪贴板粘贴）。
3. 仍失败 → 停止报告。禁止对同一内容连续输入三次。
4. 剪贴板：粘贴前备份、任务后恢复；恢复失败必须在汇报中说明。

## 4. 滚动失败（页面没动）

1. 先判断页面是否本来不可滚（内容不足一屏、已滚到底）。
2. 可滚但没动：换幅度或方向再试一次，验证移动。
3. 仍不动 → 停止该方向滚动并报告。禁止重复同一手势超过 2 次、禁止连续狂滚。

## 5. 加载/网络等待

- 转圈或加载中：最多等 15 秒，期间周期性重新观察，**不点击**。
- 超时 → 报告（可能是网络问题），建议用户检查网络；经同意可重试一次。

## 6. App 闪退/卡死

- 重新打开一次；再失败 → 停止报告。

## 7. 键盘遮挡目标

- 用「收起键盘」按钮或安全的空白区域收起键盘，再操作目标。
- 注意：搜索场景里乱点空白可能取消搜索，优先用收起键。

## 8. 重试预算（全局）

- 单个动作：最多 3 次尝试。
- 整个任务：最多 2 轮完整重试。
- 触顶 → 停止，输出报告：已完成 / 未完成 / 不确定各是什么，最后观察到的画面，建议的人工收尾步骤。

## 9. 任何情况下立即停止（无需预算判断）

- 用户叫停。
- 镜像断开。
- 出现支付、身份验证、生物识别界面。
- 出现本技能禁止操作的确认框。
