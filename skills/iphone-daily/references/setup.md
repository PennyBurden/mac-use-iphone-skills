# 环境准备与基础能力自检

任何任务开始前，把本文件流程跑一遍（每个会话一次）。目的：把「能不能做」和「怎么做」分开，先确认能做。

## 1. iPhone 镜像条件（引导用户人工确认）

按 Apple 官方要求：

- Mac：macOS 15 或更高，已安装 iPhone 镜像（/System/Applications/iPhone Mirroring.app）。
- iPhone：iOS 18 或更高，支持连续互通的机型。
- 两台设备登录**同一 Apple 账户**，且都开启了双重认证。
- 蓝牙与 Wi-Fi 已开启，iPhone 在附近，处于**锁定**状态。
- 镜像窗口**不能**使用 iPhone 的摄像头、麦克风或 Face ID——涉及这些的任务直接不支持，不做尝试。

用户应先手动打开一次镜像并确认可以人工点击、输入，再交给 agent。

## 2. 宿主 agent 权限（按所用客户端）

- 需要屏幕截图（屏幕录制）权限与鼠标键盘控制（辅助功能/自动化）权限，具体名称与开启路径依客户端而定。
- ZCode 桌面端：在系统设置中为运行 ZCode 的应用授予相应权限后重启客户端。

## 3. 四项基础能力自检（agent 执行）

逐项做，每项都有明确的通过标准。**全部通过后才允许执行正式任务**。

### 3.1 截图

- 动作：对 iPhone 镜像窗口截图。
- 通过：截图里能辨认出 iPhone 屏幕内容（如锁屏时间或主屏幕图标）。
- 失败处理：无截图能力，所有任务不可执行。

### 3.2 点击

- 动作：回到 iPhone 主屏幕 → 点击「时钟」图标 → 确认时钟 App 打开 → 返回主屏幕。
- 通过：看到时钟界面出现，且能回到主屏幕。
- 失败处理：不执行任何依赖点击的任务（即 v1 全部任务）。

### 3.3 滚动

- 动作：打开「设置」→ 在主列表向下滚动一屏。
- 通过：滚动后首个可见条目发生变化（页面真的动了）。
- 失败处理：查车次、比价任务不可执行（都依赖滚动），如实记录失败表现。
- 说明：iPhone 镜像下的滚动兼容性已有公开用户反馈，必须真机验证，不能靠提示词保证。

### 3.4 中文输入

- 动作：新建一条备忘录草稿 → 输入「测试_中文标点，。」→ 回读核对 → 删除该草稿。
- 通过：回读文字与目标逐字一致（含标点）。
- 失败处理：备忘录任务不可执行；记录是「直接键入」还是「剪贴板粘贴」失败。
- 注意：若用剪贴板粘贴，先备份原剪贴板内容，测试结束后恢复，恢复不了要报告。

## 4. 自检失败后的规则

- **不绕过**：不要用替代手段硬做任务（例如用方向键模拟滚动、用多次小点击模拟拖动）。
- **如实报告**：哪项失败、现象是什么。
- **可选升级路径**：只有当原生滚动或输入被真机测试证实不稳定后，才评估接入现成 MCP（如 mirroir-mcp）；必须先在本机真机验证可用再启用，不能仅凭 README 判断可用。

## 5. 记录

每次会话的自检结果记入 evals/results.md 的环境记录表（日期、macOS/iOS 版本、客户端与模型、四项结果）。
